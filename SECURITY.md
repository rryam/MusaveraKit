# Security Policy

## Supported Versions

MusaveraKit currently targets the Xcode 27 beta SDK. Security fixes are applied
to the `main` branch and to the latest tagged release once stable releases
begin.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Older commits and prereleases | No |

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Email [contact@rryam.com](mailto:contact@rryam.com) with:

- a description of the issue and its impact
- the affected API or source file
- reproduction steps or a proof of concept
- any suggested mitigation

You should receive an acknowledgment within seven days. Please allow time to
investigate and prepare a fix before disclosing the issue publicly.

## Scope

Reports about MusaveraKit's source and package configuration are in scope.
Issues in Apple's MusicUnderstanding framework, Apple operating systems, or the
Xcode beta should be reported to Apple through Feedback Assistant.
