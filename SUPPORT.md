# Support

## Bugs in MusaveraKit

Use the [bug report form](https://github.com/rryam/MusaveraKit/issues/new?template=bug_report.yml)
for reproducible problems in this package. Include the exact Xcode build,
operating-system build, and package commit or tag.

## Feature Requests

Use the [feature request form](https://github.com/rryam/MusaveraKit/issues/new?template=feature_request.yml)
for focused API proposals and workflow improvements.

## Apple Framework Issues

If the same behavior occurs when using MusicUnderstanding directly, file the
report with Apple through [Feedback Assistant](https://feedbackassistant.apple.com).
Link the Feedback Assistant number in a MusaveraKit issue when a package
workaround may still be useful.

## Security

Do not report vulnerabilities in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).

## General Questions

For usage questions, open a GitHub issue with a small reproducible example.
Please avoid sharing copyrighted audio or private user-library data.
